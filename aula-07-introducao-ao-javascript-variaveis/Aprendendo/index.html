Iniciação ao JS

Essa é a nossa primeira interação com JS em aulas! Por isso, começaremos do ZERO!

Diferença entre as tecnologias

O HTML na verdade é uma linguagem de Marcação, ele cuida das partes estruturais de um site.

O CSS é uma linguagem de Estilização, ele cuida das partes visuais de um site.

O JS é uma linguagem de Programação, ele cuida das partes funcionais e interativas de um site.

Origem do JS

O JavaScript foi criado em 1995 por Brendan Eich, um programador da Netscape Communications Corporation. Inicialmente, o JavaScript foi desenvolvido em apenas 10 dias e lançado como parte do navegador Netscape Navigator 2.0.

A linguagem foi projetada para ser uma linguagem de script leve e fácil de usar, permitindo que os desenvolvedores adicionassem interatividade e dinamismo às páginas da web. Desde então, o JavaScript evoluiu significativamente e se tornou uma das linguagens de programação mais populares e amplamente utilizadas na web.

Java Script não é Java

Apesar do nome, o JavaScript não tem relação direta com a linguagem de programação Java. O nome "JavaScript" foi escolhido por motivos de marketing, aproveitando a popularidade do Java na época.

O JavaScript é uma linguagem de script interpretada, enquanto o Java é uma linguagem de programação compilada. Além disso, o JavaScript é executado principalmente em navegadores web, enquanto o Java pode ser usado para desenvolver aplicativos independentes e aplicativos móveis.

Por motivos de patente, o nome "JavaScript" foi substituído por "ECMAScript", para evitar conflitos com a marca "Java"

Declaração de Variáveis em JS

O JS só aceita nomes de variáveis que começam com uma letra, um underscore (_) ou um cifrão ($). E deve estar escrito em padrão camelCase.

Uma variável não pode conter os seguintes aspectos:

  • Espaços
  • Caracteres especiais (exceto underscore e cifrão)
  • Palavras reservadas da linguagem

Em JavaScript, existem três maneiras principais de declarar variáveis: usando as palavras-chave var, let e const.

  • var: É a forma mais antiga de declarar variáveis em JavaScript. Variáveis declaradas com var têm escopo de função, o que significa que elas são acessíveis em toda a função em que foram declaradas. Ela pode ser reatribuída e redeclarada. No entanto, o uso de var é desaconselhado em favor de let e const, que oferecem um escopo mais previsível.
  • let: Introduzido no ECMAScript 6 (ES6), o let permite declarar variáveis com escopo de bloco, ou seja, elas só são acessíveis dentro do bloco em que foram declaradas. Elas podem ser reatribuídas, mas não podem ser redeclaradas no mesmo escopo.
  • const: Também introduzido no ES6, o const é usado para declarar constantes, ou seja, valores que não podem ser reatribuídos após a declaração. Assim como o let, as constantes têm escopo de bloco. Ela não pode ser redeclarada nem reatribuída. É importante notar que objetos e arrays declarados com const podem ter seus conteúdos modificados.

O JS é uma linguagem dinamicamente tipada, ou seja, ela define o tipo de dado de uma variável em tempo de execução. Não é necessário declarar o tipo de uma variável explicitamente.

Como criar exatamente este JavaScript

Abaixo está a explicação completa do que foi feito no código do seu JavaScript. Vou te mostrar cada parte, como funciona e para que serve.

1. Declarando variáveis

Primeiro, criamos variáveis para guardar dados que o usuário vai digitar ou que o programa vai usar. Em JavaScript, usamos var, let e const.

var nome = "Guilherme";

Essa linha cria uma variável chamada nome e guarda o texto Guilherme. O var é uma forma mais antiga de declarar variáveis, mas ainda aparece em vários códigos.

let cidade = "Registro";

O let é mais moderno e recomendado. Ele cria uma variável que pode mudar de valor depois, por exemplo:

cidade = "São Paulo";

Isso significa que você pode trocar o valor da variável depois.

const idade = 16;

O const serve para criar uma constante. Isso quer dizer que o valor não pode ser mudado depois de declarado. Por isso, o JavaScript avisa erro se você tentar fazer algo como:

idade = 17;

2. Entrada de dados com prompt

Em seguida, usamos window.prompt() para solicitar dados ao usuário. Essa função abre uma caixa de diálogo e o usuário escreve um valor, que será armazenado na variável.

var nome = window.prompt("Digite seu nome: ");

Esse valor entra como texto, ou seja, como string. O JavaScript lê tudo como texto por padrão, até você converter para número.

let cidade = window.prompt("Digite sua cidade: ");

A variável cidade recebe o texto digitado pelo usuário. Depois, podemos sobrescrever esse valor com outro texto, como no seu exemplo:

cidade = "São paulo"; const idade = Number(window.prompt("Digite sua idade: "));

Aqui a função Number() converte o valor digitado em um número. Isso é essencial quando você quer fazer operações matemáticas. Sem essa conversão, a idade poderia ser tratada como texto.

3. Saída na tela com document.write

O document.write() escreve um conteúdo diretamente na página. Ele é muito usado para mostrar mensagens, valores de variáveis e resultados.

document.write(nome);

Isso mostra o valor da variável nome na página.

document.write("
");

Esse trecho cria uma quebra de linha. É como se fosse um Enter dentro da página HTML.

4. Concatenação

A concatenação é a junção de textos ou valores em uma mesma string. Em JavaScript, usamos o sinal +.

document.write("Eu moro em " + cidade + "
");

Esse código junta o texto "Eu moro em ", o valor da variável cidade e a quebra de linha. O resultado final é algo como "Eu moro em São paulo".

5. Template string e placeholder

A versão mais moderna e elegante de concatenar textos é usar template strings, com crases ` e a sintaxe ${}.

document.write(`Eu moro em ${cidade}
`);

O ${cidade} é o placeholder. Ele indica: "coloque o valor da variável cidade aqui". Isso deixa o código mais legível e organizado.

6. Verificando o tipo da variável

O operador typeof mostra o tipo do valor guardado em uma variável.

typeof nome typeof idade typeof cidade

Isso ajuda a saber se a variável é uma string, number, boolean etc.

7. Alerta para o usuário

O comando alert() aparece como uma popup na tela do usuário. Ele é usado para avisos, mensagens de boas-vindas ou confirmação.

alert(`Olá, ${nome}! Seja bem-vindo ao meu site!`);

Aqui o código usa o valor da variável nome dentro da mensagem, com template string.

8. Calculando com números

Quando você quer somar dois números que vieram do usuário, precisa primeiro transformar os valores em número.

const num1 = Number(window.prompt("Digite o primeiro número: ")); const num2 = Number(window.prompt("Digite o segundo número: ")); const soma = num1 + num2;

Esse trecho pede dois valores, converte ambos para número e faz a soma. Depois mostra o resultado na tela.

9. Transformando texto

A linguagem JavaScript também oferece métodos para alterar texto.

nomeCompleto.toUpperCase()

Esse comando transforma tudo em letras maiúsculas.

nomeCompleto.toLowerCase()

Esse comando transforma tudo em letras minúsculas.

10. Formatando números e moedas

Para formatar valores monetários, usamos toFixed() e toLocaleString().

salario.toFixed(2)

Isso mostra o valor com duas casas decimais, como 2500.00.

salario.toLocaleString("pt-BR", { style: "currency", currency: "BRL" })

Esse código formata o valor em moeda brasileira, exibindo "R$ 2.500,00". Em outras palavras, ele adapta o valor para o padrão do Brasil.

11. Resumo final

O seu JavaScript faz exatamente isso:

  • pega dados do usuário;
  • salva em variáveis;
  • converte valores quando necessário;
  • faz operações matemáticas;
  • mostra mensagens e resultados na página;
  • formata texto e valores para deixar a saída mais bonita.

Esse é o básico da programação em JavaScript: receber dados, processar e mostrar o resultado.
